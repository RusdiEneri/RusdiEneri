# Tentang Saya
> 🇬🇧 Prefer English? [Read the English version](./README.md)

Saya adalah mahasiswa **Backend & Network Engineering** yang berdomisili di **Tuban, Indonesia**, dengan minat yang kuat pada **web development, backend systems, Linux infrastructure, dan networking**. Saya senang membangun aplikasi praktis serta berbagai tools infrastruktur yang dapat menyelesaikan permasalahan nyata, sekaligus terus memperdalam pemahaman mengenai system administration, network security, dan API development.

Pengalaman saya mencakup **packet analysis, konfigurasi firewall, DNS filtering, Linux services, automation, serta pengembangan aplikasi backend**. Saya juga senang bereksperimen dengan layanan self-hosted dan berbagai proyek infrastruktur kecil untuk memahami bagaimana sebuah sistem bekerja, mulai dari application layer hingga network layer.

Saat ini saya sedang mendalami **Network Security, Linux System Administration, API Development, dan Infrastructure Automation**, sambil terus meningkatkan kemampuan melalui proyek pribadi dan eksperimen secara langsung.
