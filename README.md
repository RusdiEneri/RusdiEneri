# About Me 
> 🇮🇩 Prefer Indonesian? [Baca versi Bahasa Indonesia](./README.id.md)

I'm a Backend & Network Engineering student based in **Tuban, Indonesia**, with a strong interest in **web development, backend systems, Linux infrastructure, and networking**. I enjoy building practical applications and infrastructure tools that solve real-world problems while continuously improving my understanding of system administration, network security, and API development.

My experience includes working with **packet analysis, firewall configuration, DNS filtering, Linux services, automation, and backend application development**. I also enjoy experimenting with self-hosted services and small infrastructure projects to better understand how systems work from the application layer down to the network.

Currently, I'm exploring **Network Security, Linux System Administration, API Development, and Infrastructure Automation**, while continuing to strengthen my skills through personal projects and hands-on experimentation.
