### ⚙️ Engineering Principles

* **Zero-Bloat Architecture:** Building lean services that solve target problems cleanly without unnecessary runtime dependencies or performance-sapping wrappers.
* **Protocol-Level Precision:** Working directly with foundational protocol layers (*Protobuf, WebSocket, HTTP/2, DNS*) to achieve maximum throughput and predictable latency.
* **DNS Resilience & Defense:** Hardening network perimeters against telemetry and threats through packet inspection, recursive local DNS sinkholes (*AdGuard Home*), and strict segmentation.
* **Measurable Reliability (Benchmarks):** Rejecting performance assertions without empirical evidence. Every optimization is verified against real stress tests and sub-millisecond telemetry.
